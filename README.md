# RedirectVPNspoof

Веб-приложение (Python/Flask) для создания «заглушек» HTTP-запросов: вы вставляете
целевой URL и набор заголовков (в формате JSON или Python-словаря), сервер выполняет
запрос (по умолчанию GET) и генерирует публичную ссылку на результат (статус, заголовки
и тело ответа).

## Возможности
- Базовый вход по логину и паролю.
- При первом запуске создаётся случайный аккаунт администратора (данные печатаются в
  консоль и сохраняются в `data/admin_credentials.txt`).
- Добавление запроса (URL + заголовки) → мгновенный GET → генерация ссылки `/r/<token>`.
- Просмотр всех выходных данных запроса по сгенерированной ссылке.

## Локальный запуск
```bash
pip install -r requirements.txt
python -m app.main
# или
gunicorn app.main:app --bind 0.0.0.0:5000
```
Откройте http://localhost:5000 и войдите под сгенерированным админом.

## Деплой на Railway
1. Залейте репозиторий в GitHub.
2. В Railway создайте проект из этого репозитория (авто-детект через `Procfile`/`railway.json`).
3. В разделе **Variables** задайте:
   - `ADMIN_USERNAME` — ваш логин администратора;
   - `ADMIN_PASSWORD` — ваш надёжный пароль;
   - `SECRET_KEY` — длинная случайная строка для защиты сессий.
4. Перезапустите сервис. Указанные `ADMIN_USERNAME` и `ADMIN_PASSWORD` будут
   применены и к уже созданной базе данных, поэтому ими можно восстановить доступ.
5. Стартовая команда уже указана в `Procfile` / `railway.json`.

Не записывайте реальные пароли в репозиторий или исходный код. Храните их только в
переменных окружения Railway.

## Структура
```
app/
  config.py      настройки и пути
  db.py          SQLite, пользователи и сохранённые запросы
  proxy.py       разбор заголовков и выполнение HTTP-запроса
  routes.py      маршруты (login, dashboard, view)
  templates/     HTML-шаблоны
  main.py        точка входа для gunicorn
```
